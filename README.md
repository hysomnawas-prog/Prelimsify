# Prelimsify organized project

## Structure

- `index.html` — page structure and UI markup
- `css/styles.css` — all page styling
- `js/app.js` — application logic, Supabase integration, question loading, test logic, and fullscreen handling

## Question formats

The application currently supports JSON and both supported `.hysom` text formats.

## Running

For local development, serve this folder through a local HTTP server rather than opening `index.html` directly. This is especially useful for native browser fullscreen and Supabase authentication.
